# AI Fitness Trainer

A complete AI-powered fitness trainer web application designed for direct hosting on GitHub Pages.

## How to Deploy to GitHub Pages

1. Download and extract `AI-Fitness-Trainer.zip`.
2. Push all extracted files directly to your GitHub repository's `main` branch.
3. In your repository settings on GitHub, navigate to **Settings** -> **Pages**.
4. Set **Source** to `Deploy from a branch`, choose `main` / `/ (root)`.
5. Click **Save**.
